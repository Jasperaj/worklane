IRD Toolkit
Runs entirely against ird.gov.np from this server, using your own PAN and login each time. Nothing is stored between requests.

TDS list & bulk PDF download

Stable

Fetches every withheld TDS transaction for your PAN in a date range, then can bundle every submission's official PDF into one ZIP.

VAT filing status check

Depends on portal internals

Logs in with your own PAN, then checks whether VAT returns were filed for a list of PANs, a tax year, and a period.

Date extension - apply

Live submission

Submits a real filing-date extension application to IRD for your own PAN. Double-check every field - there is no undo.

Date extension - download PDF

Depends on portal internals

Retrieves your approved extension document as a PDF.

eTax payment voucher lookup

Manual token needed

Talks to a separate system (etax.ird.gov.np) with its own short-lived login token. Log into etax.ird.gov.np in your browser, open DevTools -> Network, open any API request, and copy the value after Bearer in its Authorization header. It usually expires within the hour.

ETDS transaction & voucher detail

Depends on portal internals

For a list of ETDS submission numbers, logs in per submission on the secondary IRD host and pulls transaction detail and voucher detail rows. Can also bundle everything - a 3-sheet Excel workbook plus each submission's English-language PDF - into one ZIP.
